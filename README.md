# 🔐 Password Generator

A clean and responsive Password Generator built using **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- 🔑 Generates random passwords
- 📋 One-click Copy button
- 🎨 Responsive and modern UI
- ⚡ Fast password generation
- 🖱️ Copy button appears only after a password is generated

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Click **Generate** to create a password.
4. Click **Copy** to copy it to your clipboard.
